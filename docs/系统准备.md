# 三套系统准备说明

## 通用要求

实验环境建议使用 Ubuntu 22.04。系统源码可放在任意位置，通过适配器的 `--repo` 参数传入；不要把第三方源码和构建产物提交到课程仓库。

课程固定版本记录在 `adapters/versions.json`。完成编译后，应先运行对应适配器的 `doctor`，检查源码提交、课程数据和可执行程序。

## PipeANN-Filter

源码仓库：<https://github.com/thustorage/PipeANN>

适配器期望：

```text
<repo>/build/tests/build_disk_index_filtered
<repo>/build/tests/search_disk_index_filtered
```

常见依赖包括 CMake、C++ 编译器、AIO/io_uring、BLAS/MKL、Eigen 和 Google perftools。具体构建方法以课程固定提交的 README 为准。

检查示例：

```bash
python3 adapters/pipeann_adapter.py doctor \
  --repo /path/to/PipeANN \
  --dataset-root "$PWD/datasets/yfcc_course_v1" \
  --tier debug
```

## GateANN

源码仓库：<https://github.com/GyuyeongKim/GateANN-public>

```bash
git clone https://github.com/GyuyeongKim/GateANN-public.git
git -C GateANN-public checkout 71e87cbf0e25c0400c0109dd25a64a7c4dccc9dd
```

适配器期望：

```text
<repo>/build/tests/build_disk_index
<repo>/build/tests/search_disk_index_yfcc
```

若出现 `gperftools/malloc_extension.h` 缺失，需要安装 Google perftools 的开发包。其他依赖和构建选项以固定提交的 README 为准。

## Filtered-DiskANN

源码仓库：<https://github.com/microsoft/DiskANN/tree/cpp_main>

课程实验使用旧版 C++ `cpp_main` 分支，而不是新版 DiskANN3 主分支：

```bash
git clone --branch cpp_main --single-branch https://github.com/microsoft/DiskANN.git
git -C DiskANN checkout 78256bbab4685e1774e78d331e081a153be26823
```

适配器期望：

```text
<repo>/build/apps/build_disk_index
<repo>/build/apps/search_disk_index
```

若 CMake 报告找不到 Boost `program_options`，需要安装相应 Boost 开发包。其他依赖和构建选项以固定提交的 README 为准。
