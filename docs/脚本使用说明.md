# 脚本使用说明

本文说明课程仓库中各脚本的用途、输入、输出、主要参数和重试行为。除非特别说明，所有命令都应在课程仓库根目录执行。

基础实验只需要依次完成“下载数据 → 准备源码 → 构建 Debug 索引 → Debug 验证 → 下载 Formal 索引 → Formal 实验”。`Filtered-DiskANN` 适配器和仓库回归测试均为可选内容。

## 一、基础实验命令顺序

```bash
# 1. 下载并校验课程数据集
bash scripts/download_dataset.sh
bash scripts/check_dataset.sh

# 2. 下载固定版本源码并完成编译
bash scripts/prepare_pipeann.sh
bash scripts/prepare_gateann.sh

# 3. 在 10 万向量 Debug 数据上构建两套索引
python3 adapters/pipeann_adapter.py build \
  --repo "$PWD/systems/PipeANN" \
  --dataset-root "$PWD/datasets/yfcc_course_v1" \
  --tier debug --run-root "$PWD/course_runs" --threads 8

python3 adapters/gateann_adapter.py build \
  --repo "$PWD/systems/GateANN-public" \
  --dataset-root "$PWD/datasets/yfcc_course_v1" \
  --tier debug --run-root "$PWD/course_runs" --threads 8

# 4. 运行 Debug 查询并验证结果
bash scripts/run_debug_validation.sh

# 5. 下载并校验 100 万向量 Formal 预构建索引
bash scripts/download_indexes.sh
bash scripts/check_indexes.sh

# 6. 运行统一正式实验并汇总结果
bash scripts/run_formal_experiments.sh
```

## 二、脚本总览

| 命令 | 学生是否直接运行 | 作用 | 主要输出 |
| --- | --- | --- | --- |
| `scripts/download_dataset.sh` | 是 | 下载、校验并解压课程数据集 | `datasets/yfcc_course_v1/` |
| `scripts/check_dataset.sh` | 是 | 检查数据集全部文件的 SHA-256 | 终端校验结果 |
| `scripts/prepare_pipeann.sh` | 是 | 获取固定版本 PipeANN 并编译课程目标 | `systems/PipeANN/build/` |
| `scripts/prepare_gateann.sh` | 是 | 获取固定版本 GateANN、应用兼容补丁并编译 | `systems/GateANN-public/build/` |
| `adapters/pipeann_adapter.py` | 是 | 检查环境、构建索引或运行 PipeANN 查询 | 索引目录或结果目录 |
| `adapters/gateann_adapter.py` | 是 | 检查环境、构建索引或运行 GateANN 查询 | 索引目录或结果目录 |
| `scripts/run_debug_validation.sh` | 是 | 运行两套系统的 Debug 查询并检查正确性 | `course_runs/results/` |
| `scripts/download_indexes.sh` | 是 | 下载、校验并解压两套 Formal 索引 | `course_runs/indices/` |
| `scripts/check_indexes.sh` | 是 | 检查 Formal 索引内容、版本和校验值 | 终端校验结果 |
| `scripts/run_formal_experiments.sh` | 是 | 按课程固定参数完成全部正式实验 | `course_runs/experiments/` |
| `scripts/check_debug_results.py` | 否，自动调用 | 检查 Debug 结果字段和 Recall 下限 | PASS 或错误信息 |
| `scripts/collect_results.py` | 否，自动调用 | 校验并汇总 Formal 单次结果 | `results.csv` |

## 三、数据集脚本

### 1. `download_dataset.sh`

```bash
bash scripts/download_dataset.sh
```

- 输入：`config/dataset.env` 中的数据集下载地址、文件名和 SHA-256。
- 输出：默认下载到 `datasets/`，并解压为 `datasets/yfcc_course_v1/`。
- 行为：检查 `curl`、`sha256sum`、`tar` 和 `zstd`；校验压缩包后才会解压；解压完成后自动调用数据集检查脚本。
- 重试：下载中断后可直接重新执行，脚本会尝试续传。若数据集目录已存在，脚本只做校验，不覆盖已有数据。

如需把数据放在其他父目录，可在执行前设置：

```bash
FVS_DATASET_PARENT=/path/to/datasets bash scripts/download_dataset.sh
```

### 2. `check_dataset.sh`

```bash
bash scripts/check_dataset.sh [数据集目录]
```

- 输入：可选的数据集目录；默认是 `datasets/yfcc_course_v1/`。
- 输出：仅输出检查结果，不修改数据集。
- 检查内容：读取数据包中的 `checksums.sha256`，逐文件验证完整性。
- 失败处理：不要手工修改数据文件。删除或移走损坏的数据集目录后重新下载。

## 四、源码准备脚本

### 1. `prepare_pipeann.sh`

```bash
bash scripts/prepare_pipeann.sh [PipeANN 源码目录]
```

- 默认源码目录：`systems/PipeANN/`。
- 输入：`adapters/versions.json` 中固定的源码仓库和 Commit。
- 输出：Release + AIO 配置的 PipeANN 构建目录及课程所需可执行文件。
- 并行度：默认使用 8 个编译任务；内存较小或编译失败时可降低，例如：

```bash
FVS_BUILD_JOBS=4 bash scripts/prepare_pipeann.sh
```

### 2. `prepare_gateann.sh`

```bash
bash scripts/prepare_gateann.sh [GateANN 源码目录]
```

- 默认源码目录：`systems/GateANN-public/`。
- 输入：固定的源码仓库、Commit，以及 `patches/gateann_aio_compat.patch`。
- 输出：Release + AIO 配置的 GateANN 构建目录及课程所需可执行文件。
- 补丁：课程兼容补丁会以可重复执行的方式应用，无须学生手工修改源码。
- 并行度：同样由 `FVS_BUILD_JOBS` 控制。

两个准备脚本都可以直接重跑。若源码目录位于错误 Commit 且没有本地修改，脚本会切换到课程固定版本；若目录存在本地修改且 Commit 不正确，脚本会拒绝继续，以免覆盖学生代码。

## 五、系统适配器

两套必做适配器使用相同的三级子命令：

```bash
python3 adapters/pipeann_adapter.py doctor|build|search [参数]
python3 adapters/gateann_adapter.py doctor|build|search [参数]
```

### 1. `doctor`：环境检查

示例：

```bash
python3 adapters/pipeann_adapter.py doctor \
  --repo "$PWD/systems/PipeANN" \
  --dataset-root "$PWD/datasets/yfcc_course_v1" \
  --tier debug
```

`doctor` 检查源码 Commit、构建类型、AIO 配置、所需可执行文件和数据文件。Commit 不等于课程指定值时会严格报错。该命令只做检查，不修改源码、索引或数据。

### 2. `build`：构建索引

基础实验只要求在 `--tier debug` 上构建。课程默认参数为 `R=32`、`L_build=64` 和 `PQ_bytes=32`；PipeANN 还使用 `R_dense=256`。未经教师说明，不要修改这些参数。

常用参数：

| 参数 | 含义 | 基础实验取值 |
| --- | --- | --- |
| `--repo` | 对应系统源码目录 | `systems/PipeANN` 或 `systems/GateANN-public` |
| `--dataset-root` | 课程数据集根目录 | `datasets/yfcc_course_v1` |
| `--tier` | 数据规模 | `debug` |
| `--run-root` | 索引和结果的根目录 | `course_runs` |
| `--threads` | 索引构建线程数 | 默认示例为 `8`，可按机器调整 |
| `--R` | 图出度 | `32` |
| `--L-build` | 构建搜索宽度 | `64` |
| `--reuse-existing` | 接受并复用已存在的成功索引 | 仅确认索引正确时使用 |
| `--dry-run` | 打印底层命令但不执行 | 排查路径或参数时使用 |

构建采用临时目录发布机制：成功后才把索引放入正式目录；失败产物和日志会保留在带 `.failed-` 标记的目录中。构建失败后可直接重跑原命令。若正式索引已经成功存在，脚本默认拒绝覆盖，需显式添加 `--reuse-existing`。

### 3. `search`：运行单组查询

正式实验通常不需要手工调用 `search`，统一实验脚本会按固定参数调用。需要单独排错时可使用：

```bash
python3 adapters/pipeann_adapter.py search \
  --repo "$PWD/systems/PipeANN" \
  --dataset-root "$PWD/datasets/yfcc_course_v1" \
  --tier debug --run-root "$PWD/course_runs" \
  --bucket high --threads 1 --beamwidth 8 --k 10 --L 40 \
  --run-id my-debug-run
```

常用参数：

| 参数 | 含义 |
| --- | --- |
| `--bucket` | Filter Workload 档位：`low`、`medium` 或 `high` |
| `--L` | 搜索预算，可一次给出一个或多个值 |
| `--k` | 返回近邻数，课程实验固定为 `10` |
| `--threads` | 查询线程数，课程实验固定为 `1` |
| `--beamwidth` | SSD beam width，课程实验固定为 `8` |
| `--run-id` | 本次运行标识，用于隔离输出目录 |
| `--dry-run` | 只打印底层命令，不执行查询 |

每次查询在以下位置生成 `command.json`、`run.log` 和 `results.csv`：

```text
course_runs/results/<system>/<tier>/<bucket>/<run-id>/
```

同一路径下已存在结果时，适配器会拒绝覆盖。请换一个 `--run-id`；这也保证了原始实验记录不会被误删。

## 六、Debug 验证脚本

```bash
bash scripts/run_debug_validation.sh \
  [PipeANN 源码目录] [GateANN 源码目录] [运行根目录]
```

- 前提：两套 Debug 索引已经通过适配器的 `build` 命令构建成功。
- 输入：默认使用课程数据集、默认源码目录和 `course_runs/`。
- 执行：先对两个系统运行 `doctor`，再运行 High workload 查询；PipeANN 使用 `L=40`，GateANN 使用 `L=320`。
- 验证：自动调用 `check_debug_results.py`，核对退出状态、系统、数据规模、查询数、`K`、`L`、线程数、beam width，并要求 Recall@10 不低于 80%。
- 输出：`course_runs/results/*/debug_100000/high/<run-id>/`。
- 重试：默认 run-id 含时间戳，可直接重新执行且不会覆盖旧结果。若自行设置了固定 `FVS_DEBUG_RUN_ID`，重试前需要更换该值。

注意：该脚本只运行查询和正确性检查，不负责构建 Debug 索引。

## 七、正式索引脚本

### 1. `download_indexes.sh`

```bash
bash scripts/download_indexes.sh
```

- 输入：`config/indexes.env` 中两套索引的下载地址、文件名和 SHA-256。
- 输出：默认解压到 `course_runs/indices/`。
- 行为：支持下载续传；压缩包校验通过后才会解压；已有索引不会被静默覆盖。
- 重试：网络中断后可直接重跑。索引目录已存在时会进行校验。

空间不足时可以把完整运行目录放到其他 SSD。下载脚本的 `FVS_INDEX_ROOT` 必须与正式实验的 `<运行根目录>/indices` 一致，例如：

```bash
FVS_INDEX_ROOT=/path/to/course_runs/indices \
FVS_INDEX_DOWNLOAD_DIR=/path/to/course_runs/downloads \
bash scripts/download_indexes.sh

bash scripts/check_indexes.sh /path/to/course_runs/indices
bash scripts/run_formal_experiments.sh \
  "$PWD/systems/PipeANN" "$PWD/systems/GateANN-public" \
  /path/to/course_runs
```

### 2. `check_indexes.sh`

```bash
bash scripts/check_indexes.sh [索引根目录] [pipeann|gateann|all]
```

- 默认检查：`course_runs/indices/` 下的全部索引。
- 检查内容：逐文件 SHA-256、系统名称、数据集发布版本和 Formal tier。
- 行为：只读检查，不修改索引。

## 八、正式实验与结果汇总

```bash
bash scripts/run_formal_experiments.sh \
  [PipeANN 源码目录] [GateANN 源码目录] [运行根目录]
```

脚本会先检查数据集、正式索引、源码 Commit 和构建配置，然后记录 CPU、内存、存储设备、编译器、源码版本及补丁校验值。随后按 `config/experiments.env` 中的统一参数运行实验：

- 默认独立重复 3 次；
- 每次为每套系统运行 5 个配置；
- High workload 使用 3 档搜索预算；
- Medium 和 Low 各使用 1 档代表性搜索预算；
- 两套系统每次共 10 行、默认最终共 30 行结果。

输出目录：

```text
course_runs/experiments/<experiment-id>/environment.txt
course_runs/experiments/<experiment-id>/results.csv
course_runs/results/<system>/formal_1000000/<bucket>/<run-id>/
```

`collect_results.py` 会在实验结束时自动校验单次结果并生成聚合表。它不绘图，也不计算中位数；图表和统计分析由学生根据实验说明完成。

默认 experiment-id 含时间戳，因此失败后可重新执行并保留旧记录。若设置了固定的 `FVS_EXPERIMENT_ID`，不要用同一 ID 覆盖已有实验；请更换 ID 后重新运行。该脚本不提供中途续跑功能。

## 九、路径与运行标识

常用环境变量如下：

| 环境变量 | 作用 | 默认值 |
| --- | --- | --- |
| `FVS_BUILD_JOBS` | 两套系统的编译并行度 | `8` |
| `FVS_DATASET_PARENT` | 数据集下载和解压的父目录 | 仓库内 `datasets/` |
| `FVS_DATASET_ROOT` | Debug/Formal 脚本读取的数据集目录 | `datasets/yfcc_course_v1/` |
| `FVS_INDEX_ROOT` | 正式索引下载脚本的输出目录；应为 `<运行根目录>/indices` | `course_runs/indices/` |
| `FVS_INDEX_DOWNLOAD_DIR` | 正式索引压缩包缓存目录 | 脚本默认下载目录 |
| `FVS_DEBUG_RUN_ID` | Debug 验证的运行标识 | 自动生成时间戳 |
| `FVS_EXPERIMENT_ID` | 正式实验标识 | 自动生成时间戳 |
| `FVS_REPEATS` | 正式实验重复次数 | `3` |

`FVS_DATASET_PARENT` 只影响下载位置；将数据集下载到仓库外后，还需设置 `FVS_DATASET_ROOT` 供 Debug 和 Formal 脚本读取。自定义索引位置时，应把正式实验的第三个位置参数设置为索引父目录对应的运行根目录。正式实验的搜索参数已统一写入 `config/experiments.env`，未经教师说明不要修改。

## 十、自动脚本与可选内容

- `scripts/check_debug_results.py`：由 Debug 验证脚本自动调用，一般不需要单独运行。
- `scripts/collect_results.py`：由正式实验脚本自动调用，一般不需要单独运行。
- `adapters/filtered_diskann_adapter.py`：Filtered-DiskANN 自选扩展适配器，不属于基础实验，也不参与统一正式实验。
- `python3 -m unittest discover -s tests -v`：仓库维护者用于检查适配器行为的回归测试，不是学生实验步骤。

遇到依赖、磁盘空间、内存或 Windows 环境问题，请先查阅 [系统准备说明](系统准备.md)；实验任务和提交要求见 [实验说明](实验说明.md)；正式实验结束后的字段、统计和绘图方法见 [结果分析指南](结果分析指南.md)。
