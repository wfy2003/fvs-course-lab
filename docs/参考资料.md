# 参考文献与源码入口

本页给出完成课程实验所需的论文与源码入口。课程准备脚本使用固定源码提交，以保证不同同学的实验环境和输出格式一致；请勿直接用仓库最新版本替换课程固定版本。

## 阅读要求

完成基础实验需要了解以下三篇论文的核心设计：

1. **PipeANN**：理解 SSD-resident 图搜索的基本流程，以及计算、SSD I/O、搜索预算、Recall 和延迟之间的关系；
2. **PipeANN-Filter**：理解推测式过滤、不同过滤执行路径及动态路由选择；
3. **GateANN**：理解 Pre-I/O Filtering、Graph Tunneling，以及减少无效 I/O 所付出的索引空间和计算代价。

不要求逐行掌握论文中的证明、全部实验或实现细节。能够结合系统结构解释本课程测得的 Recall、延迟、I/O 和内部指标即可。

有余力的同学可以进一步阅读 **DiskANN** 和 **Filtered-DiskANN**，了解底层 SSD 图索引、Vamana 构建方法，以及标签感知图构建与过滤搜索的其他设计。两篇论文不是完成基础实验的前置要求。

## 建议的源码阅读入口

完成环境准备后，可从以下文件开始阅读。无需通读整个仓库，优先沿课程使用的查询入口追踪关键路径。

### PipeANN / PipeANN-Filter

- `tests/search_disk_index_filtered.cpp`：课程使用的过滤查询程序与指标输出入口；
- `src/search/pipe_search.cpp`：PipeANN 的 SSD 流水化搜索实现；
- `src/search/spec_filter_search.cpp`：PipeANN-Filter 的推测式过滤与路由逻辑；
- `include/filter/`：过滤器、属性存储和谓词相关实现。

### GateANN

- `tests/search_disk_index_yfcc.cpp`：课程使用的 YFCC 查询程序与指标输出入口；
- `src/search/pipe_search.cpp`：Pre-I/O Filtering 与 Graph Tunneling 的搜索逻辑；
- `include/utils/spmat_filter_store.h`：YFCC 多标签过滤信息的存储与访问；
- `include/utils/full_adj_index.h`：Graph Tunneling 使用的 FullAdj 数据结构。

## 推荐阅读顺序

1. 先阅读 PipeANN，建立 SSD-resident 图搜索和流水化执行的基本认识；
2. 再阅读 PipeANN-Filter 与 GateANN，比较两套系统在过滤位置、图可达性和 I/O 控制方面的设计；
3. 完成 Debug 实验后，结合日志中的实际指标阅读对应机制与源码；
4. 如希望理解技术脉络或完成扩展，再阅读 DiskANN 与 Filtered-DiskANN。
